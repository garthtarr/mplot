# Package index

## Core functions

- [`af()`](https://garthtarr.github.io/mplot/reference/af.md) : The
  adaptive fence procedure
- [`vis()`](https://garthtarr.github.io/mplot/reference/vis.md) : Model
  stability and variable inclusion plots
- [`bglmnet()`](https://garthtarr.github.io/mplot/reference/bglmnet.md)
  : Model stability and variable importance plots for glmnet
- [`mplot()`](https://garthtarr.github.io/mplot/reference/mplot.md) :
  Model selection and stability curves
- [`lmfence()`](https://garthtarr.github.io/mplot/reference/lmfence.md)
  : The fence procedure for linear models
- [`glmfence()`](https://garthtarr.github.io/mplot/reference/glmfence.md)
  : The fence procedure for generalised linear models
