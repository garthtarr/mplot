# mplot: Graphical Model Stability and Variable Selection Procedures

Model stability and variable inclusion plots \[Mueller and Welsh (2010,
[doi:10.1111/j.1751-5823.2010.00108.x](https://doi.org/10.1111/j.1751-5823.2010.00108.x)
); Murray, Heritier and Mueller (2013,
[doi:10.1002/sim.5855](https://doi.org/10.1002/sim.5855) )\] as well as
the adaptive fence \[Jiang et al. (2008,
[doi:10.1214/07-AOS517](https://doi.org/10.1214/07-AOS517) ); Jiang et
al. (2009,
[doi:10.1016/j.spl.2008.10.014](https://doi.org/10.1016/j.spl.2008.10.014)
)\] for linear and generalised linear models.

## References
